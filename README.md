**VRAM Guard** was the original open-source thermal protection utility for laptop GPUs. This repository contains the legacy version (v1.4.2) and is kept here for historical purposes.

### 🌟 What's new in VRAM Shield?

While VRAM Guard provided the foundation with **Pulse Throttling**, the new **VRAM Shield** takes hardware safety to a professional level:

*   **Smart Throttling (PRO):** A brand-new engine using advanced mathematical logic for smoother performance and maximum hardware safety.
*   **Modern UI:** Completely redesigned interface with real-time hardware monitoring charts.
*   **Multi-language Support:** Now available in 8 languages.
*   **Enhanced Stability:** Support for the latest Windows 10/11 updates and modern GPU architectures.
